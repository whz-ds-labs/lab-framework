# @whz-ds-labs/lab-kit

Framework-free core and Vue runtime for DS Labs teaching tools (CSV parsing, seeded RNG, number formatting,
URL query parsers, shared state).
Framework-freier Kern und Vue-Laufzeit für DS-Labs-Lehrwerkzeuge (CSV-Parser, Zufallsgenerator mit Seed,
Zahlenformatierung, URL-Query-Parser, geteilter Zustand).

```
npm install @whz-ds-labs/lab-kit vue
```

Requires Node >= 24.15 / Benötigt Node >= 24.15. License: MIT.
