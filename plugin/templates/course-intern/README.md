## Deutsch

## English

Private repo for the course `%%course%%`. It holds course material and the working documents of the labs (analyses, specifications, plans). **Never make this repo public.**

- `materials/`: slides, notebooks and scripts of the course (only here, never in the public repo `%%course%%`)
