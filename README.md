# DS Labs Framework

## Deutsch

Dieses Repository enthält das DS-Labs-Framework: die npm-Pakete `@whz-ds-labs/lab-kit` und `@whz-ds-labs/ui` sowie das Claude-Plugin `ds-labs` zum Aufbau interaktiver Lehrlabore für Data-Science-Kurse. Der Einstieg steht im Handbuch: [docs/de/01-start.md](docs/de/01-start.md).

## English

This repository contains the DS Labs framework: the npm packages `@whz-ds-labs/lab-kit` and `@whz-ds-labs/ui` and the Claude plugin `ds-labs` for building interactive teaching labs for data science courses. Start with the handbook: [docs/en/01-start.md](docs/en/01-start.md).
